電気とガスの小売自由化（電気は2016年4月、都市ガスは2017年4月）以降、関東では多くの会社が電気とガスのセットプランを出しています（資源エネルギー庁「電力の小売全面自由化」、「ガス小売全面自由化」）。「セットにすると割引」と言われると得に見えますが、実際には、電気だけ・ガスだけで見るともっと安い会社があることも少なくありません。

この記事では、生活費ラボ編集部が、関東（東京ガスの都市ガス供給エリア）を例に、セット割と別々契約のどちらが安いかを自分の検針票の数字で計算する方法を解説します。例として取り上げる各社の条件は、2026年10月時点の公式サイトで確認したものです。利用者の体験談ではなく、公開情報にもとづく整理です。電力会社の乗り換え全般の考え方は「電気・ガスの乗り換えで固定費を下げる｜比較の4条件」で解説しています。

セット割の3つのパターン

「電気とガスのセット割」と一口に言っても、割引の付き方は会社によって違います。比べる前に、どのパターンかを確認してください。

パターン仕組み比べるときの注意
電気の単価が下がるガスとセットにすると、電気の1kWhあたりの料金が一定額引かれる電気の使用量が多いほど割引額が大きい
料金の一定率が割り引かれる電気またはガスの料金から一定の割合が引かれる割引の対象が「基本料金のみ」「電力量料金のみ」など限定されていないか
ポイント・特典が増えるセットにするとポイントの還元率が上がるポイントを使い切れるか、現金換算でいくらか

セット割と別々契約を比べる計算方法

比べ方は単純です。次の4つの数字を出して、年間の合計で比べます。

  1. 今の年間の電気代とガス代（検針票の夏と冬の2か月分から推計）
  2. セットプランにした場合の電気代＋ガス代−セット割引
  3. 電気だけ最も安い会社にした場合の電気代＋ガスだけ最も安い会社にした場合のガス代
  4. 2と3を比べ、さらに解約金・初期費用・キャンペーンの条件を加味する
計算の型（数字は計算方法を示すための例）
電気の使用量夏400kWh・冬450kWh検針票の「ご使用量」
ガスの使用量夏15m³・冬45m³ガスは冬に大きく増える
セット割（例: 電気1円/kWh引き）月400円〜450円引き年間で約5,000円前後
判断別々契約との差が年間5,000円未満ならセットが有利逆なら別々が有利

夏と冬で使用量が大きく違うため、1か月分だけで判断しないことが大切です。特にガスは冬に使用量が大きく増えるので、ガス料金の差が大きい会社を選ぶと、冬の差額で年間の結論が変わることがあります。

関東で検討しやすい選択肢と条件

Looopでんき（電気・ガスセット、市場連動型）

Looopでんきの公式サイトでは、関東エリアで、東京ガスの都市ガス供給エリアに住む人向けに電気とガスのセットを案内しています（2026年10月時点）。確認できた主な条件は次のとおりです。

  • 電気のプラン「スマートタイムONE」は電源料金が30分ごとに変わる市場連動型。市場高騰時の上限単価が設定されている
  • 電気とガスをセットで契約すると電気が1kWhあたり1円割引
  • 電気・ガスとも解約手数料0円、契約期間の制限なし
  • キャンペーンとして、2026年10月30日までの新規申し込みで3,000円割引（2026年12月31日までに電気とガスの両方の供給開始が条件）
  • 申し込みには、今の電気とガスの検針票（お客さま番号など）が必要

市場連動型は、卸電力市場の価格が安い時間帯に電気を多く使える家庭ほど有利になりやすい一方、市場価格が上がる時期は請求額が上がりやすいという特徴があります。洗濯や食洗機、充電などの時間をずらせるか、毎月の請求額の変動を受け入れられるかを考えてから選んでください。

関東の都市ガスエリアで、電気とガスをまとめたい場合

電気とガスのセットで電気が1kWhあたり1円割引になるプランです。電気は30分ごとに単価が変わる市場連動型なので、使う時間をずらせるか、月々の変動を許容できるかを確認してから検討してください。解約手数料は0円と案内されています。

エルピオでんき（解約金なし、電気単独でも申し込み可）

エルピオでんき（株式会社エルピオ、千葉県市川市）の公式サイトとよくある質問では、次の条件が確認できます（2026年10月時点）。

  • 契約期間・違約金はなく、いつでも解約できる
  • ガスとのセットは必須ではなく、でんきのみの申し込みが可能
  • 提供エリアは東京電力・中部電力・関西電力・東北電力・北陸電力・中国電力・四国電力・九州電力の各エリア
  • スマートメーター未設置の場合は設置工事が発生するが、原則として費用負担はない
  • 支払いはクレジットカード（全エリア）、口座振替（東京電力エリアのみ）

「電気は電気で安い会社、ガスはガスで安い会社」と別々に選びたい人にとって、電気単独で申し込めて解約金がない会社は比較の候補にしやすい選択肢です。料金プランはエリアごとに異なるため、自分のエリアの料金表で今の電気代と比べてください。

電気だけを先に見直したい場合

契約期間・違約金がなく、ガスとセットにしなくても電気だけで申し込める新電力です。エリアごとの料金プランで、検針票の使用量をもとに今の電気代と比べてから検討してください。

セット割より別々契約が有利になりやすいケース

  • 電気の使用量が少ない一人暮らし: 「1kWhあたり◯円引き」型のセット割は、使用量が少ないと割引額も小さくなります
  • ガスをあまり使わない家庭（オール電化に近い、シャワー中心など）: ガスのセット割の恩恵が小さくなります
  • 電気かガスのどちらかに、極端に安い単独プランがある: 片方の差額だけでセット割を上回ることがあります
  • 引っ越しの予定がある: セットの一方だけ解約すると割引がなくなる、新居がエリア外になる、といったことがあります

セット割が有利になりやすいケース

  • 電気の使用量が多い家庭（3人以上、在宅時間が長い）: 単価割引型のセット割は使用量に比例して効きます
  • 支払いや問い合わせ先をまとめたい: 請求が1つになり、管理の手間が減ります
  • セット限定のキャンペーンがある時期: ただし条件（両方の供給開始期限など）を満たせるかを確認します

プロパンガス物件はセット割の前に「ガス会社の料金」を確認

ここまでの話は都市ガスの物件が前提です。プロパンガス（LPガス）の物件は、都市ガス会社のセット割の対象になりません。プロパンガスは料金が自由料金で、同じ地域でも会社によって単価の差が大きいのが特徴です。電気のセット割を考えるより先に、プロパンガスの単価が相場と比べて高すぎないかを確認するほうが、固定費を下げる効果が大きい場合があります。

  • 相場の確認: 「プロパンガスの平均価格｜地域別の相場と比べ方」
  • 請求書の読み方: 「プロパンガス請求書の見方｜三部料金制の確認点」
  • 賃貸の場合: 「賃貸のプロパンガスは変更できる？交渉の手順」

戸建てでプロパンガスを使っている場合は、ガス会社の切り替えを検討できます。プロパンガス会社の比較サービス「エネピ」（運営: 株式会社じげん）は、公式サイトで、見積もり・契約変更は無料、戸建て・賃貸・店舗に対応、受付時間は10時〜21時と案内しています。賃貸の場合は、ガス会社の契約者が大家であることが多いため、まず管理会社・大家への相談が前提です。

プロパンガスの料金が高いと感じたら

使用状況をもとに、プロパンガス会社の料金を比較・紹介する無料のサービスです。戸建て・賃貸・店舗に対応しています。賃貸の場合は、大家・管理会社への相談が前提になります。

比較で見落としやすい4つの項目

1. 再エネ賦課金はどの会社でも同じ

電気料金には「再生可能エネルギー発電促進賦課金」が含まれます。これは使用量に応じて全国一律の単価でかかるため、どの電力会社を選んでも差は出ません。比較するときは、検針票の合計額から再エネ賦課金を除いて比べると、会社ごとの差がはっきりします。

2. 燃料費調整額と市場価格調整の違い

多くの電力会社は、燃料の輸入価格に連動する「燃料費調整額」を毎月加減します。一方、市場連動型のプランは、卸電力市場の価格そのものが単価に反映されます。同じ「単価が変わる」でも、変わり方の仕組みが違うため、過去1年程度の実績単価を公式サイトで確認できる場合は確認しておくと安心です。

3. ガスの基本料金は使用量の区分で変わる

都市ガスの料金表は、使用量の区分ごとに基本料金と単位料金が設定されていることが一般的です。冬に使用量が増えると区分が変わり、基本料金も変わることがあります。夏と冬の2か月分で計算するのはこのためです。

4. 支払い方法による手数料・ポイント

口座振替やクレジットカード払いの可否、請求書払いの手数料は会社によって違います。カード払いにするとポイントが付く分、実質の負担が下がることもあります。エルピオでんきのように、エリアによって選べる支払い方法が異なる会社もあるので確認してください。カード払いの考え方は「電気代のクレカ払いはどれだけ得？ポイント二重取り術」で整理しています。

セット割・乗り換えの前に確認すること

  • 夏と冬の検針票（電気のkWh、ガスのm³）を用意したか
  • セット割の対象（電気の単価・料金の一定率・ポイント）と、割引の上限を確認したか
  • 電気とガスをそれぞれ単独で最も安い会社にした場合と比べたか
  • 解約金・契約期間（セットの片方だけ解約した場合の扱い）を確認したか

  • キャンペーンの条件（申し込み期限・供給開始期限）を満たせるか
  • オール電化・プロパンガスなど、対象外の条件に当てはまらないか

よくある疑問

電気とガスを別々の会社にすると不便ですか

請求と問い合わせ先が2つになる点以外、使い勝手は変わりません。電気もガスも、送配電網・導管は地域の事業者が維持しているため、契約先を変えても停電やガスの供給の安定性は変わらないのが一般的です。

セット割の片方だけ解約するとどうなりますか

多くの場合、セット割引がなくなり、残った契約は単独の料金になります。解約金の有無は会社ごとに異なるため、約款や重要事項説明で確認してください。Looopでんきは解約手数料0円と案内しています。

市場連動型プランは危なくないですか

卸電力市場の価格が上がる時期は請求額が上がるリスクがあります。Looopでんきは上限単価を設定していると案内していますが、毎月の変動を許容できるか、使う時間をずらせるかで向き不向きが分かれます。

プロパンガスの物件でも電気のセット割は使えますか

都市ガス会社のセット割は、都市ガスの契約が前提のため使えません。プロパンガスの物件では、電気は電気で比較し、ガスはプロパンガス会社の料金を確認するのが現実的です。
